# Learn Arduino

Personal Arduino learning exercises focused on Embedded Systems and Modern C++.

| Sketch                              | Purpose                                        |
| ----------------------------------- | ---------------------------------------------- |
| `01_blink_led`                      | Digital Output, `digitalWrite()`, LED Control  |
| `02_button_input`                   | Digital Input, `digitalRead()`, `INPUT_PULLUP` |
| `03_led_toggle`                     | Edge Detection, Button Press Events            |
| `04_timed_led`                      | Non-Blocking Timing using `millis()`           |
| `05_reaction_timer`                 | State Machines, Random Delays                  |
| `06_traffic_light_controller`       | Finite State Machine (FSM)                     |
| `07_electronic_dice`                | Random Numbers, Binary Output                  |
| `08_knight_rider_scanner`           | Arrays, Direction Control                      |
| `09_led_class`                      | Classes, Constructors, Encapsulation           |
| `10_button_class`                   | Debouncing, Hardware Abstraction               |
| `11_led_array_scanner`              | Arrays of Objects                              |
| `12_reaction_game_oop`              | OOP + State Machines                           |
| `13_traffic_light_class`            | Composition (Class owns Classes)               |
| `14_serial_command_controller`      | UART, Serial Communication                     |
| `15_multi_led_controller`           | String Parsing, Command Processing             |
| `16_traffic_light_controller_class` | Controller Pattern, Encapsulation              |
| `17_interrupt_button`               | Interrupts, ISR, Event Driven Programming      |
| `18_multi_timer_scheduler`          | Multiple Timers, Cooperative Scheduling        |
| `19_task_scheduler_struct`          | Structs, Data Modelling                        |
| `20_dynamic_led_sequence`           | Pointers, Array Decay, Generic Functions       |
| `21_generic_task_scheduler`         | Pointers, Scheduler Class, Generic Components   |
| `22_callback_scheduler`             | Function Pointers, Callbacks, Decoupled Tasks   |
